# Проверка сборки 0.1

Дата: 2 октября 2026. Windows x64, AMD Radeon RX 6750 XT, Godot 4.5.1 stable.

## Автоматические проверки

- `tests/test_simulation.gd`: **62 проверки, 0 ошибок**. Допустимость состава, цены и специализированные ресурсы, урон и высота, лимиты роботов/снарядов, захват с отменой, доход, ядерный взрыв, маршрутизация, защита базы тактическим AI, однократные сюжетные события, испорченные сохранения, детерминированное продолжение сохранения, победа/поражение.
- На каждой из четырёх карт симуляция выполнялась 2000 тактов: проверены наличие сторон, постройка и приказы AI, ограничения армии, загрузка снимка состояния.
- `tests/test_ui.gd`: **17 проверок, 0 ошибок**. Главное меню, список и загрузка исходной карты, сборка с изменением конфигурации и вызовом кнопки выпуска, прямое управление, приказ, сохранение/загрузка через интерфейс, пауза, продолжение симуляции и финальный рапорт.
- Проверено, что тест интерфейса восстанавливает существовавшие до него пользовательские сохранения.

## Нативная сборка и графика

Экспорт выполняется официальным Windows release-шаблоном. EXE содержит игровой пакет; для проверки копируется один EXE в отдельный каталог и запускается с этим каталогом как рабочим.

- Vulkan / Forward+, первая глава: тестовый запуск, симуляция и снимок кадра.
- OpenGL / Compatibility, исходная карта: тестовый запуск и симуляция.
- Визуально просмотрены главное меню, игровой HUD, сборка робота и справка. Исправлены обрезание списка приказов и слишком мелкая модель в сборочном предпросмотре.
- Устранены сообщения OpenGL об оставшихся текстурах при закрытии: приложение освобождает сцену и даёт рендеру завершить несколько кадров перед выходом.

Снимки находятся в `build/menu.png`, `build/assembly.png`, `build/gameplay.png`, `build/help.png`; логи выпуска — в `build/`.

## Что не проверено

- Побитовая/потактовая эквивалентность ZX Spectrum: см. `FIDELITY.md`.
- Полное ручное прохождение всех глав и долговременный баланс кампании.
- Другие GPU, Windows ARM, Linux/macOS, контроллеры и мультимониторные режимы.
- Длительные стресс-тесты пользовательских карт максимального размера.

Успех автоматических проверок не заменяет эти виды проверки.
